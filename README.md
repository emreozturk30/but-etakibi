# Bütçe Takip

Kişisel gelir/gider takip uygulaması. Proje kuralları ve yol haritası için
[PLAN.md](./PLAN.md) dosyasına bakın.

## Yığın

- React + TypeScript + Vite
- Veri kalıcılığı: tarayıcı localStorage (backend yok)

## Geliştirme

```bash
npm install
npm run dev
```

## Diğer komutlar

```bash
npm run build    # üretim derlemesi
npm run lint     # oxlint ile kod kontrolü
npm run preview  # üretim derlemesini yerelde önizleme
```
